> [!info]  info about default inkscape shortcuts
> Most default F-key shortcuts used for tools should be changed.  

<br/>

## External links

https://en.wikibooks.org/wiki/A_Guide_to_Inkscape/Appendix_A:_Keyboard_Shortcuts

## Dialogs

| Action               | Hotkeys                                           |
|----------------------|---------------------------------------------------|
| Fill and Stroke      | <kbd>Shift</kbd> + <kbd>Ctrl</kbd> + <kbd>F</kbd> |
| Layers               | <kbd>Shirt</kbd> + <kbd>Ctrl</kbd> + <kbd>L</kbd> |
| Align and Distribute | <kbd>Shift</kbd> + <kbd>Ctrl</kbd> + <kbd>A</kbd> |
| Export Bitmap        | <kbd>Shift</kbd> + <kbd>Ctrl</kbd> + <kbd>E</kbd> |
| Document Properties  | <kbd>Shift</kbd> + <kbd>Ctrl</kbd> + <kbd>D</kbd> |
| Text Properties      | <kbd>Shift</kbd> + <kbd>Ctrl</kbd> + <kbd>T</kbd> |
